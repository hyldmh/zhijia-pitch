⚙️ 核心技術架構

   📱 用戶端（手機 H5/App）
   ├── WebRTC  (聲網/騰訊雲) ──── 音視頻實時傳輸
   ├── WebSocket                 ──── 控制信令
   └── WebXR (ARKit/ARCore)      ──── AR 試擺
   
              ↓ HTTPS/WSS
            
   ☁️ 雲端 AI Orchestrator (FastAPI)
   ├── ASR (阿里雲/火山)        ──→ 中文即時識別
   ├── VLM (Qwen2.5-VL-7B)     ──→ 房間照片分析
   ├── LLM (GPT-4o Realtime)    ──→ 全雙工對話
   ├── TTS (edge-tts / CosyVoice) ──→ 串流語音合成
   └── Function Calling
       ├── 🔍 商品 RAG (Qdrant 向量庫)
       ├── 💰 庫存/價格 (PostgreSQL)
       ├── 📦 訂單/物流 API
       └── 🏭 3D 模型庫 (S3 + CDN)

   🛒 後台 SaaS (Medusa.js + EspoCRM)

所有模塊都是 開源 或 現成 API
